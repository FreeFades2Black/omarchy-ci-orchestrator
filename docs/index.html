About This Project

This platform is a fully autonomous, closed-loop CI/CD intelligence and continuous remediation pipeline. Operating as decoupled systemd user daemons on an Arch Linux workstation (Omarchy), the system audits an entire fleet of personal and organization GitHub repositories, identifies security vulnerabilities and out-of-date GitHub Actions, and automatically prepares, opens, and squash-merges remediation pull requests.

Intelligence is harvested asynchronously from the CISA Known Exploited Vulnerabilities (KEV) catalog, NIST SP 800-218 guidelines, arXiv cs.SE/cs.CR preprints, and OpenAlex citations. Feed records and upstream GitHub Action release tags are cached in an embedded SQLite database running in Write-Ahead Logging (WAL) mode to protect GitHub API limits. Remote failure detection runs continuously on a companion Windows machine via an SSH polling watchdog that triggers native Windows 10/11 desktop notifications and audio alarms on service failure.
